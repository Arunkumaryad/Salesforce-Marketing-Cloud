## 1. Data Models in Salesforce Marketing Cloud

Salesforce Marketing Cloud supports **two data models** for storing and managing subscriber data:

| Data Model | Description |
|---|---|
| **List Based Data Model** | Uses **Lists** to store subscribers. |
| **Contact Based Data Model** | Uses **Contacts** (a unified, relational view of a person across channels). |

**In simple words:** Every Marketing Cloud account manages its subscriber/customer data using one (or both) of these two approaches — Lists are the simpler, older model, while Contacts are the newer, more relational model.

---

## 2. List Based Data Model

**Definition:** The List Based Data Model is built around three core ideas:

- It is a **collection of subscribers that receive only one type of communication** from the company.
- It is a **Non-Relational data model** (i.e., data is not linked across multiple related tables the way relational databases work).
- It is **used to store individual studio records** (records specific to a channel, like Email Studio).

**In simple words:** A List is essentially a simple, standalone group of subscribers meant for a single purpose (e.g., "Newsletter Subscribers" or "Promo Offers List"). It doesn't automatically connect to other data about the same person elsewhere in Marketing Cloud — each List exists on its own.

---

## 3. When to Use a List

Lists are the right choice when:

1. **You have a collection of up to 500,000 subscribers.**
2. **The fast import of data collection is not a great concern to you** — in an hour, you can upload up to 500,000 rows.
3. **You only have a few attributes in mind to segment your subscribers** (i.e., your targeting/segmentation needs are simple).

**In simple words:** Lists work best for smaller subscriber volumes, simple segmentation needs, and situations where you don't need complex, relational customer data — just a straightforward group of people to send one type of message to.

---

## 4. Data Types in a List

A List supports three basic data types for its attributes:

| Data Type | Description |
|---|---|
| **Text** | Alphanumeric/string values (e.g., Name, City). |
| **Numeric** | Number values (e.g., Postcode, Age). |
| **Date** | Date values (e.g., Birthday, Signup Date). |

**In simple words:** When you set up custom fields/attributes for a List, you can only choose from these three simple data types — keeping the List structure lightweight and easy to manage.

## 5. Navigating to Subscribers

Lists are managed under the **Subscribers** menu in **Email Studio**:

**Path:** `Email → Subscribers`

The **Subscribers** dropdown includes:
- All Subscribers
- **Lists**
- Groups
- Profile Management
- Preference Management
- Data Extensions
- Salesforce Data Extensions
- Shared Data Extensions
- Shared Salesforce Data Extensions
- Data Relationships
- Publication Lists
- Shared Publication Lists
- Suppression Lists
- Shared Suppression Lists
- Data Filters
- Measures

For working with the List Based Data Model, the relevant option is **Lists**.

## 6. Creating a List

Steps to create a new List:

1. Go to **Email → Subscribers → Lists**.
2. Browse to the folder where you want to create the list (e.g., under **My Lists → [your folder]**).
3. Click **Create**.
4. Name the list (e.g., *Test List1*) and save it.
5. Once created, the list shows:
   - **Name**
   - **Type** (e.g., Standard)
   - **Subscriber Count**
   - **Last Modified Date**
   - **Status** (e.g., Available)

Opening a List shows three tabs:
- **Properties** – basic list settings/name.
- **Subscribers** – the actual subscriber records in this list, with actions like **Search, Delete, Copy, Import, Export**, and **Create**.
- **Tracking** – engagement/tracking data for the list.

## 7. Adding a Subscriber to a List

Steps to manually add a subscriber via the **Create Subscriber Wizard**:

1. Open the List → **Subscribers** tab → click **Create**.
2. In the **Create Subscriber Wizard** (step: *Identify Subscriber*), enter:
   - **Subscriber Key** — a unique identifier for the subscriber (e.g., `Arun07Test01`).
   - **Email Address** (e.g., `arun@sraban.com`).
3. Fill in the **Profile Attributes**, such as:
   - FirstName
   - LastName
   - Cumpleaños *(Birthday)*
   - Country
   - State
   - Postcode
4. Scroll to view/fill **Preference Attributes** as well (additional columns available via horizontal scroll).
5. Click **Next** to continue through the wizard, then complete and save.

**In simple words:** The Subscriber Key uniquely identifies each person in the system (even if their email changes later), while Profile Attributes store the actual personal details used for personalization and segmentation.

### Quick-Fire Definitions
- **List** → A non-relational collection of subscribers that receive one type of communication.
- **Subscriber Key** → A unique identifier assigned to each subscriber record.
- **Profile Attribute** → A data field describing a subscriber (e.g., Name, Country).
- **Preference Attribute** → A data field capturing a subscriber's communication preferences.
- **Data Type (List)** → Text, Numeric, or Date — the only supported field types in a List.
